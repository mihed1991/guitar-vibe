# Настройка Telegram-заявок на PHP

1. Убедитесь, что на сервере включён PHP 7.4+. Расширения `mbstring` и `curl` желательны, но обработчик имеет запасной режим без них.
2. Скопируйте `config.example.php` в `config.php`.
3. В `config.php` укажите токен бота, длинный ключ управления и новый домен в `allowed_origins`.
4. Убедитесь, что PHP может записывать файлы в папку `storage`.
5. Откройте сайт, войдите в админку и перейдите в раздел «Заявки в Telegram».
6. Укажите адрес `https://ваш-домен.by/api/telegram.php`, ключ управления и один или несколько `chat_id`.
7. Нажмите «Сохранить получателей», затем «Отправить тест всем».

Для личного чата сначала откройте созданного бота в Telegram и нажмите **Start**. Токен бота хранится только в `api/config.php`, который исключён из Git.
